# Roadmap

Desi Music is currently an early-stage open-source project.

## Near term

- Improve playback error handling
- Add queue viewing and queue management
- Add pause/resume and volume controls
- Add automated tests
- Improve source compatibility and playback diagnostics
- Add structured logging

## Contributor experience

- Expand setup documentation
- Add reproducible development checks
- Add more issue templates
- Document release process

## Longer term

- Rich now-playing responses
- Per-server configuration
- Better observability and health reporting
- Modular command architecture
