# Contributing to Desi Music

Thanks for your interest in contributing.

## Development workflow

1. Fork the repository.
2. Create a focused branch for your change.
3. Install dependencies with `npm install`.
4. Keep secrets in a local `.env` file only.
5. Run `npm test` before submitting your change.
6. Open a pull request describing what changed and why.

## Pull request expectations

- Keep changes focused and easy to review.
- Avoid committing generated files, secrets, or credentials.
- Add or update documentation when behavior changes.
- Explain any new dependency in the pull request.

## Good first contributions

Documentation improvements, error-message improvements, tests, playback UX enhancements, and small bug fixes are all welcome.
